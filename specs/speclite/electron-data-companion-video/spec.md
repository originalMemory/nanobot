# Spec: electron-data-companion-video

## Why
- 真人视频伴侣需要在不同时间段和使用状态下保持生动，避免单视频循环。
- ComfyUI 生成完整视频，人物与环境不拆层；素材按场景包独立管理，便于后续替换和扩展。

## Scope
- 场景包按“服装 + 场景”组织完整视频素材。
- 可见状态首期仅 `idle`（待机）和 `working`（工作中）。
- 每个状态支持多个完整视频；按清晨日出 / 白天 / 傍晚日落 / 夜晚提供时间版本。
- Electron 根据当前状态和时间段选择本地视频，播放结束后随机轮切。
- 随机选择避免连续重复，设置最短播放时间和最近播放冷却。
- 保留参考图、动作提示词、seed、workflow 和 `manifest.json`，支持后续调整与按动作倾向选择。

不做：
- 真人视频分层、Live2D 式骨骼驱动、实时重光照。
- 首期区分“思考 / 执行 / 等待工具结果”等细分工作状态。
- 首期引入小模型判断用户输入倾向。
- 首期摄像头 / 麦克风情绪识别。

## Apply Notes
- 视频保持完整画面，不拆人物和环境；时间差异通过独立完整视频体现。
- 待机和工作使用不同基础图；同一“服装 + 场景 + 时间段”下的动作视频共用对应基础图。
- 工作视频基础图使用 F2K / Flux2 Klein Edit；待机和工作动作视频使用 MiniMax H3 FL2V，同一张基础图同时作为首帧和尾帧。
- 工作基础图选定夜晚候选 `work_base_night_f2k_04.png`；清晨工作视频基础图选定 `work_base_sunrise_f2k_left_38.png`。
- 状态由系统事件驱动：任务开始进入 `working`，最终回复完成回到 `idle`。
- 工作中内部可存在思考 / 工具执行阶段，但首期统一播放 `working` 素材。
- 每个状态至少 3 条候选；同一时间段的候选使用同一参考图和视频 seed 生成，以降低人物漂移。
- 音频保留轻微环境声、呼吸声和动作声；明确禁止背景音乐、旋律、乐器和节奏声；禁止使用 `-an` 删除整条音轨。
- 素材与 Electron 程序分离，支持本地缓存和独立更新；首期可先使用本地资源目录。
- 首尾帧工作流不重复强调“回到首帧”，由尾帧图片负责循环约束。
