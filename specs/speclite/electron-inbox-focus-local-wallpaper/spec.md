# Spec: electron-inbox-focus-local-wallpaper

## Why
- 全局快捷键再次触发并隐藏收件箱后，焦点仍留在 Electron，需要恢复到此前使用的应用。
- 动态壁纸只支持网络 URL；本地图库需要目录轮播、顺序/随机选择及位置续播。

## Scope
- 本次要做：快捷键唤起前记录此前前台应用；在统一收件箱已激活时再次触发快捷键，隐藏主窗口并在 macOS、Windows 主动恢复此前应用焦点。
- 本次要做：壁纸来源支持「网络 URL / 本地目录」二选一；保留现有 URL 与间隔配置。
- 本次要做：本地目录只读取目录第一层的常见图片文件，按文件名稳定排序；支持顺序、随机模式。
- 本次要做：持久化本地目录最后展示的文件索引；顺序模式从下一张继续，随机模式避免连续重复（目录仅一张时除外）。
- 本次要做：设置页支持选择/填写本地目录、选择顺序模式；网络来源不展示或禁用顺序配置；补齐中英文 i18n 与测试。
- 本次不做：递归扫描子目录、监听目录实时变化、图片复制或缩略图缓存、浏览器 WebUI。

## Apply Notes
- macOS 快捷键隐藏用 `app.hide()` 把激活权交回先前应用，再以非激活方式恢复此前可见的辅助窗口；主窗口保持隐藏。
- Windows 唤起前记录前台窗口句柄；隐藏 Electron 后通过 Win32 前台窗口 API 恢复该句柄。句柄已失效或恢复失败时仅隐藏 Electron，由系统选择下一前台窗口。
- Windows Win32 调用由无窗口异步 `powershell.exe` 子进程完成，不阻塞 Electron 主进程；记录的句柄只对同一次快捷键唤起有效，窗口中途失焦即清理，避免恢复陈旧应用。
- 本地图片扩展名：`.jpg`、`.jpeg`、`.png`、`.webp`、`.gif`、`.bmp`、`.avif`；忽略目录与其他文件。
- `localIndex` 表示最近成功展示的排序后索引；目录内容变化时按当前文件数归一化。读图失败时跳过失败项，不覆盖当前壁纸。
- 网络模式沿用每次请求 URL 的行为；`localOrder`、`localIndex` 不参与网络请求。
- 目录选择通过主进程 `dialog.showOpenDialog({ properties: ['openDirectory'] })`，同时保留路径输入便于粘贴 NAS/本地路径。
- 配置切换使用请求代次隔离；旧网络/本地读图完成后不能覆盖新来源。
- 目录索引重置前按平台规范化路径；Windows 忽略大小写、斜杠与末尾分隔符差异。
