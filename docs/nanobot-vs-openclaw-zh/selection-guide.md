# 何时选择哪一个

[← 目录](./README.md)

## 更适合 nanobot

- 希望 **快速读懂并修改 Agent 核心循环**（Python）。
- 已有 Python 运维/自动化栈，需要 **轻量常驻 Agent + 多通道**。
- 需要 **OpenAI 兼容本地 API** 或嵌入现有 Python 服务。
- 接受较少原生客户端，以 WebUI + 聊天软件为主。
- 贡献者希望 PR 范围小、核心路径稳定（design 约束明确）。

## 更适合 OpenClaw

- 需要 **全平台个人助手**（桌面 + 移动 + 多渠道 + 语音/画布）。
- 依赖 **成熟插件生态**（大量 Provider/通道/媒体能力）。
- 需要 **标准化 Gateway 协议** 供多客户端、Node、自动化连接。
- 团队以 TypeScript/Node 为主，能接受更大仓库与更重的 CI/开发流程。
- 追求「控制平面 + 产品化」而非「框架源码可读性」。
