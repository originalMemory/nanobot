WebUI、agent/session runtime、provider/channel、cron/gateway 与安全边界都发生了持续重构。

## 上游主要变化

1. `nanobot webui` 成为一站式工作台入口，加入引导配置、话题式会话、模型 preset 切换、
   文档附件、文件 diff/预览和更完整的工具活动展示。
2. agent turn 生命周期改为 typed runtime context，加入 inline subagent，并将持续执行显式收口到
   `/goal`。
3. 网关采用 `GatewayServices`，加强配置热重载、restart/shutdown、任务取消和会话/exec 状态边界。
4. channel 改为更清晰的自包含 package，WhatsApp 切换到 Neonize，并新增 Mattermost 等接入。
5. provider/search 扩展 OpenCode、Kimi Coding、Grok OAuth、Parallel Search、Serper 等能力。
6. 修复 shell allowlist 链式命令绕过、SSRF DNS 校验、MCP URL 凭据泄露、远程 API 无鉴权暴露、
   附件入口越界等安全问题。

官方 release：
[HKUDS/nanobot v0.3.0](https://github.com/HKUDS/nanobot/releases/tag/v0.3.0)

## 采用官方新版的部分

- 采用 `GatewayServices`、`GatewayHTTPHandler`、WebSocket package/runtime 和 typed turn events。
- 采用官方 session-bound cron：绑定会话的任务自然复用原会话上下文。
- 采用 runtime-aware Dream consolidation、session retention 和 agent turn lifecycle。
- 采用官方 WebUI/API、provider/channel package、配置热重载、安全修复与部署改进。
- 删除 fork 的 `nanobot/webui/fork_http.py`，不再维护重复 HTTP handler。
- 删除 fork 的通用 cron `context_messages` 注入；新版会话绑定机制已经覆盖这个需求。

## 保留的 fork 能力

- Electron 桌面客户端。
- 统一收件箱、稳定 chat ID、消息来源元数据与跨渠道 fan-out。
- 桌面焦点/锁屏 presence、服务端截图请求和本地媒体转录接入。
- vision caption 与 preset 视觉配置刷新。
- 可检索历史会话、主动记忆召回、日记检索。
- 标准 TTS provider/tool 和 Electron 的启用/默认声音设置。
- Unraid/Docker 本地部署定制：UID/GID、仓库/配置/SSH/NAS/docker socket 挂载与 API profile。

这些能力都基于 v0.3.0 的官方运行时接口重新接入，不再替换官方网关骨架。

## 删除的 fork 能力

- PSB/THA 桌宠窗口、服务端模型存储、动作/标签/runtime metadata。
- 桌宠关联的助手消息自动播放、音频分段、播放绑定状态和 avatar route。
- `deskPet` / `desk_pet` 配置字段及用户配置中的对应块。
- 两个桌宠相关 OpenSpec change。
- THA 对 TTS 的改造；回到普通文本 TTS，后续若需要桌宠再按新版架构重做。

删除理由：这些改动与 v0.3.0 的消息、事件和网关重构冲突较深，且当前没有实际需求。保留兼容层只会让
后续上游合并继续背债。
