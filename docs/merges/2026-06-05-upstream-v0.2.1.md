## 上游主要变更（v0.2.1）

- **RuntimeEventBus**（`nanobot/bus/`）：新增运行时事件总线，替代原来散落在 loop/webui 中的状态广播
- **WorkspaceScopeResolver**（`nanobot/security/workspace_access.py`、`workspace_policy.py`）：工作区沙箱隔离机制
- **turn_continuation**（`nanobot/session/turn_continuation.py`）：turn 续写逻辑，用于判断是否需要持久化 user message
- **GatewayServices**（`nanobot/webui/gateway_services.py`）：HTTP handler 抽象层，上游将 `websocket.py` 中的 HTTP 路由迁移到独立模块
- **NapCat 频道**（`nanobot/channels/napcat.py`）：新增 QQ NapCat 协议支持
- **Azure AAD 模式**：`azure_openai` provider 支持无 api_key 的 DefaultAzureCredential 认证
- **Session 管理优化**：`retain_recent_legal_suffix` 返回更精确的 `dropped, already_consolidated`
- **WebUI 重构**：新增 `ws_http.py`、`media_api.py`、`media_gateway.py`、`settings_routes.py` 等模块，activity timeline 组件群

## 冲突文件详情

### 1. `nanobot/agent/loop.py`（12 个冲突块）

**上游改动**：引入 `WorkspaceScopeResolver`、`bind_workspace_scope`、`turn_continuation`；用 `_runtime_events()` 替代 `_webui_turns`；`ContextBuilder` 新增 `workspace_sandbox`、`runtime_events` 参数；`_pending_turn_latency_ms`/`_pending_turn_usage` 字典移除。

**Fork 独有**：`UNIFIED_SESSION_KEY`/`SessionArchiver` 导入；unified inbox fan-out 逻辑（`_fan_out_to_unified_inbox`）；`_source_extras()` 辅助方法。

**解决策略**：
- 保留 fork 的 unified inbox fan-out，但采用 upstream 的 `pending = None` 初始化模式
- 采用 upstream 的 `_runtime_events().turn_completed()` 替代 `_webui_turns.handle_turn_end()`
- `finally` 块采用 upstream 逻辑（`pending is None` 判断 + `run_status_changed`/`clear_turn`）
- `_state_finalize_turn` 合并 fork 的 `ctx.save_skip` 与 upstream 的 `latency_started_at` / `visible_run_started_at`
- 移除已不再依赖的 `_pending_turn_latency_ms`、`_pending_turn_usage`
