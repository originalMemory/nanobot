# 日常与周常学习

主动学习直接使用 nanobot 已有 Cron。仅在用户确认后创建任务；时间和时区在创建 Cron 时指定。技能不维护独立 settings、quiet hours、每日配额或调度状态。

## Daily

1. 调用 Anki adapter 获取实际到期卡，最多选择一张。
2. 有到期卡时只发送一道短题，等待用户回复；回复后才评分并决定是否展开课程。
3. 没有到期卡时调用 planner，只预告下一节点及一句学习目标，不推进节点、不记录证据、不创建卡片。
4. Anki 不可用时仍可预告课程节点，不把连接失败伪装成“没有到期卡”。

## Weekly

1. 读取结构化学习状态和 Anki review history。
2. 汇总六轨变化、已完成或降级的节点、实际 lapse 和仍未解决的错因。
3. 给出下一周最多三个重点，不规定必须完成的课程数量。
4. 只生成报告，不自动上课、评分或制卡。

Daily 和 Weekly 的 prompt 应明确要求先读取本文件及 `teaching-loop.md`；任务的启停、修改和删除均使用 nanobot Cron 自身能力。
