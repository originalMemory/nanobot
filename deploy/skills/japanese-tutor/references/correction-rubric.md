# 日语纠错标准

## 判断顺序

先理解用户想表达的意思和场景，再依次检查：

1. 句子是否成立：活用、助词、搭配、语序、指代和时态；
2. 是否自然：母语者常用搭配、省略、信息结构；
3. 语域是否匹配：书面/口语、礼貌/随意、上下级关系；
4. 语气是否符合意图：断定、委婉、请求、抱怨、亲密程度；
5. 表记是否合适：汉字、假名、标点。表记偏好通常不是语法错误。

## 反馈标签

- **错误**：会导致语法不成立或意义明显偏离；
- **可理解但不自然**：意思能懂，但搭配或信息组织不像自然日语；
- **正确但场景不合**：语法正确，礼貌程度或语体不匹配；
- **自然**：可以直接使用；若给替代说法，说明差异而不是继续挑错。

## 最小反馈格式

按任务需要选用，不必每次全部展开：

```text
原句：...
推荐：...
判断：错误／不自然／场景不合／自然
原因：只解释真正影响本句的 1～3 点
差异：替代表达的语气或使用场景
练习：一道针对本次错因的变式
```

保留用户已经写对的部分，优先做最小修改；另有更地道的整体改写时，可作为第二版本，不要用它掩盖原句具体问题。

## 翻译与作文

- 先问或推断使用场景，不逐字搬运中文结构；
- 有多个自然译法时，给一个默认版本和必要的语气差异；
- 长文先给整体可读版本，再归纳重复出现的 2～4 类问题，不逐句制造信息洪水；
- 不替用户悄悄重写到远超其水平。用于学习时，解释哪些修改值得掌握。

## 会话练习

会话中优先维持交流。小错误可在用户说完后集中纠正；只有错误会阻断理解或用户要求严格模式时才即时打断。角色扮演结束后总结最值得改的 1～3 点。

## 读音与音调

假名读音、音拍划分和音调是不同信息。没有可靠音调来源时不要凭感觉标数字或高低型；复合词、活用和语境可能影响发音。收到真实音频后也先依据转录和可观察现象反馈，不把 ASR 置信度当作完整发音评分。
