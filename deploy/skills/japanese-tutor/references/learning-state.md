# 学习档案与复习

正式档案路径为 `memory/japanese-learning.md`。不存在时只在第一次形成有效学习信息后创建，不为一次查词建档。

## 文件格式

保持短小并原地更新，不按日期追加流水账：

```markdown
# 日语学习档案

## 目标与节奏
- 目标：
- 当前侧写：假名／词汇语法／阅读／听力／口语／写作
- 学习节奏：
- 偏好与素材：

## 已掌握
- [项目]：能做到什么｜依据：最近一次表现｜更新：YYYY-MM-DD

## 易错与待加强
- [项目]：具体错因｜正确对比｜最近表现｜更新：YYYY-MM-DD

## 待复习
- [ ] YYYY-MM-DD｜项目｜提示或题型｜阶段 1

## 下次建议
- 一个最值得继续的主题
```

只记录用户真实表现，不把模型推测写成既成事实。`已掌握` 表示能在少提示下正确使用，不等于只看过一次。解决的易错项应删除或移入已掌握，避免永久贴标签。

## 轻量复习规则

这不是 FSRS，只用于会话连续性：

- 新学或答错：当天稍后或下一次学习先复现；
- 答对但费力：约 +1 天；
- 独立答对：依次约 +4、+7、+14、+30 天；
- 到期日不要求精确催促；用户主动学习时优先取已到期项目；
- 忘记则回到较短间隔，连续轻松答对则拉长；
- 一次复习优先 3～5 项，不清空积压为目标。

用户使用 Anki/FSRS 时，不在档案里维护重复排程；这里只记录薄弱点和学习方向。

## 更新时机

仅在以下情况落盘：目标或节奏改变、完成有效诊断、一个知识点出现可验证的掌握变化、发现重复错因、产生后续复习项。每次写入后复读文件，确认没有覆盖无关记录，再向用户简短说明记录了什么。
