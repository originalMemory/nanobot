# 语言事实与资料来源

## 来源优先级

按问题选择来源，不依赖单一网站：

1. 考试日期、报名、题型与规则：JLPT 官方网站及当地官方承办机构；
2. 教学框架与分级材料：日本国际交流基金会（JF Standard、Irodori 等）、NHK 教学资源；
3. 词义、词性、读音：可靠日语辞典，或明确基于 JMdict/JMnedict/KANJIDIC 的词典；
4. 音调：OJAD、NHK 发音辞典等明确标注音调的来源；
5. 真实用法：可靠语料库、母语材料和多个实际例句，用于验证搭配与语域；
6. 其他教学网站、论坛和 LLM 解释只作辅助，不作为唯一依据。

Yomitan 是词典容器和阅读工作流，不是词义本身的权威；回答时应识别其加载的具体词典。Anki 是复习工具，不决定语言事实或课程顺序。

## 查询原则

- 区分辞书义、常见实际用法和特定作品中的用法；
- 查活用词时回到辞书形，但说明原文中的活用作用；
- 例句必须与所讲释义匹配，不为展示单词拼出不自然句子；
- 用搜索结果数量判断自然度时要谨慎，固定转载、机器翻译和专名会制造假频率；
- 词源、网络流行语、方言、性别化表达和音调若来源不足，明确写“不确定”或给出地域/语境限制。

## 需要联网核实

以下内容具有时效性，回答前应联网并优先引用官方页面：JLPT 报名与考试日期、考点政策、教材当前版本、在线服务价格/功能、项目维护状态。

普通句子纠错不需要为了形式感联网。只有关键语言事实不确定、用户要求出处，或结论会影响备考决策时才查询。

## 开源项目借鉴边界

- Anki：借鉴复习反馈与调度概念，不复制整个系统；
- Yomitan：借鉴查词、来源标识和阅读中采词的工作流；
- awesome-japanese：用于发现资源，具体内容仍回到原始来源核实；
- Hanabira 等学习应用：只作为功能组合参考，不因项目存在就认为教学内容正确。

遵守各项目和词典数据的许可证；未明确许可时不批量复制课程、例句或词典内容到 workspace。
